DUNGEON WALL KIT — modular environment meshes

Coordinate convention:
- X = width
- Y = depth (front is negative Y)
- Z = height
- Most modules are 4m wide and ~3.5m tall.
- Each module is intended to snap side-by-side at X = +/-2m.

Files:
01 straight pillared
02 rectangular doorway
03 arched doorway
04 twin niches
05 shrine wall
06 treasure wall
07 collapsed wall
08 twin portal
09 corner section
00 showcase = all modules arranged for inspection

OBJ files are intentionally dependency-light and can be imported by Blender, Unreal, Unity, Godot, etc.
Geometry uses separate meshes for architectural pieces so an AI/game pipeline can further assign materials, collision, LODs, or replace props.
